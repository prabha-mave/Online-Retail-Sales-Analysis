# Online Retail Sales Analysis

## Project Overview
This end-to-end data analytics project analyzes online retail sales data to uncover customer purchasing behavior, sales performance trends, product insights, and revenue patterns.

The project includes:
- Data cleaning using Excel
- Business analysis using PostgreSQL
- Interactive dashboard creation using Power BI

---

## Tools Used
- Excel
- PostgreSQL
- Power BI

---

## Data Cleaning
Basic data cleaning was performed in Excel:
- Removed/handled null values
- Checked duplicate records
- Standardized data formatting
- Prepared dataset for SQL analysis

---

## SQL Analysis
Business insights were generated using PostgreSQL through multiple analytical queries.

### Key Analysis Performed
- Monthly revenue and sales volume analysis
- Top-selling products identification
- Revenue contribution by country
- Top customers by spending
- Average order value analysis
- Customer purchase frequency
- Peak sales hours analysis
- Revenue by weekday
- Product velocity analysis
- Market basket analysis
- Cancelled invoice impact
- RFM analysis
- Customer segmentation
- New vs returning customer analysis
- Guest vs registered customer revenue
- High-value low-selling product analysis

---

## Power BI Dashboard
An interactive Power BI dashboard was developed to visualize:
- Revenue trends
- Product performance
- Country-wise sales
- Quarterly revenue distribution
- Customer purchasing insights
- Detailed transaction analysis

---

## Key Insights
- United Kingdom generated the highest overall revenue
- Revenue showed strong growth toward year-end
- A small group of customers contributed significantly to total revenue
- Certain products consistently dominated total sales volume
- Returning customers generated higher revenue contribution
- Sales activity peaked during specific business hours
